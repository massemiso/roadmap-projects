# Roadmap.sh Backend Projects

Welcome to my repository of backend projects! This collection is part of my journey to becoming a **Junior Backend Developer**, following the project-based learning path from [roadmap.sh](https://roadmap.sh/backend/projects).

Each directory in this repository contains a standalone project designed to practice core backend concepts, such as CLI development, API integration, file system management, and data serialization.

## 🚀 Projects

### 1. [Task Tracker CLI](./task-cli)

A simple command-line interface to manage your tasks.

- **Key Features**: Add, update, delete tasks; track status (todo, in-progress, done); persistent storage using JSON.
- **Concepts**: File I/O, JSON handling, CLI argument parsing, CRUD operations.

### 2. [GitHub User Activity CLI](./github-activity)

A tool that fetches and displays recent activity for any GitHub user.

- **Key Features**: Fetches data from the GitHub REST API, displays events in a readable format.
- **Concepts**: HTTP requests, API consumption, JSON parsing, error handling.

## 🛠 Tech Stack

- **Language**: [Go (Golang)](https://go.dev/)
- **Standard Library**: Built using only the Go standard library (no external frameworks) to deepen understanding of the language fundamentals.

## 📖 How to Run

Most projects can be run directly using the Go toolchain. Navigate to a project directory and use:

```bash
go run . [arguments]
```

Or build the binary:

```bash
go build -o app
./app [arguments]
```
